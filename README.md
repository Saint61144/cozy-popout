# Cozy Popout

Cozy Popout adds compact YouTube playback controls and a button to open the browser’s native Picture-in-Picture window. The optional Windows companion puts the same controls on your desktop.

- [Download Cozy Desktop for Windows](downloads/Cozy-Desktop-4.3.2-Windows.zip?raw=true)
- [Download the browser extension](downloads/Cozy-Popout-No-Worker-4.3.2.zip?raw=true)

1. Extract the extension ZIP, or use the `extension` folder inside the desktop ZIP.
2. Open the Extensions page in Brave, Chrome, or Edge. Enable **Developer mode**, select **Load unpacked**, and choose the extension folder.
3. On YouTube, click **Float video**. The extension toolbar menu also has playback controls.
4. For desktop controls, extract the desktop ZIP, open **CozyDesktop.exe**, select your browser, and press **Connect**. Leave **Connect Cozy** open, then click the small Reiner icon on your desktop.

Cozy sends playback state from the extension to the Windows companion on the same computer. See [Privacy and local changes](PRIVACY.txt) for its permissions and [Build instructions](source/BUILD.txt) to compile the desktop app yourself.
